# Misc

General-purpose skills without a dedicated theme.

- **[ambitious-prompts](ambitious-prompts/SKILL.md)**: turns simple requests into more ambitious prompts when greater depth or scope is wanted.
- **[bookmarks](bookmarks/SKILL.md)**: sets up and manages the OKF bookmark collection, saving websites with dated screenshots or finding resources.
- **[web-search](web-search/SKILL.md)**: routes web work (find, read, map, crawl, act) to Exa, Firecrawl Local, TinyFish or browse.
- **[viralize](viralize/SKILL.md)**: the "false belief → hook → truth" formula for creating or fixing viral content hooks on social media.
