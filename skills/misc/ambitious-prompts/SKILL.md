# Ambitious prompts

Help the user aim higher with a model. Ambition can mean doing the same work faster, pursuing the outcome behind the requested task, doing the task with expert-level depth, or bringing in useful methods from other fields. Choose the kind of ambition that fits the work; do not equate ambition with a larger deliverable.

## Method

1. Preserve the user's goal and constraints. Look for a useful upgrade in these four dimensions:
   - **Speed:** do the same work in less time. Use when speed is the real opportunity.
   - **Altitude:** move from the requested artifact to the outcome it should create. Ask what should happen next and what the goal beyond the goal is. Consider whether a better ongoing workflow would serve that outcome than a one-off deliverable.
   - **Depth:** approach the problem as a leading professional in the field would. Start from raw data or source material, challenge assumptions against it, and use the field's actual methods and tools. Look for new knowledge, not a more polished summary of what is already known.
   - **Range:** reframe nouns as verbs to expose the real work, then draw on other disciplines when their methods could improve the result. Ask the model to use those methods, not to role-play those professionals.
2. Choose only the dimensions that fit. Set an ambitious, concrete objective; when useful, propose a stretch target as a hypothesis and state how it can be checked.
3. Specify the inputs, methods, and tools needed. Surface missing data or access instead of assuming it is available.
4. Define an independent way to judge the result: for example, held-out data, a reproducible tool, user response, or an external expert. Do not rely on the model to certify its own work.
5. Rewrite the request as a ready-to-use prompt that preserves the user's intent and makes the upgraded outcome and its evidence clear.

## Delivery

When asked to improve a prompt, return the chosen dimension or dimensions, the rewritten prompt, and any assumptions or required access that could change the result. Ask a question only when a missing decision materially changes the goal or risk; otherwise state a reasonable assumption and proceed.

When the user also asks you to do the task, use the upgraded prompt as guidance and stay within the scope and permissions they gave. Treat a more ambitious target as a hypothesis, not a guarantee.
