# Bookmark taxonomy

## Rules

1. Reuse a registered category or tag when it fits.
2. Keep categories broad and reusable.
3. Use tags for reusable topics; keep one-off details in the bookmark description.
4. Keep names in English, lowercase, unaccented, and hyphen-separated.
5. Update this registry whenever a bookmark adds a category or tag.
6. Assign no more than five tags to a bookmark.
