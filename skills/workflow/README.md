# Workflow

Skills for running agent work while you step away, and for catching up when you return. Built for a home repo: one repository where every session starts.

- **[coast](coast/SKILL.md)**: away mode. Records your instructions, routes decisions to issues, and notifies you while you are gone.
- **[sitrep](sitrep/SKILL.md)**: situation report. Recaps what happened since a point in time and clears open decisions one at a time.

`coast` runs a one-time setup on first use; see [coast/setup.md](coast/setup.md).
