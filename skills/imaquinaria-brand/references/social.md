## Posts de Instagram — estructura visual

### Post de promoción / stamp card
```
Fondo: #FFFFFF o #F5F4F2
- Isotipo dragón: esquina superior derecha, ~120px
- Elemento visual de producto: centro-izquierda, 55% del área
- Bloque de texto (fondo #E81036, borde-radius 16px):
    - Titular: League Spartan 800, blanco, mayúsculas
    - Subtítulo: Archivo regular, blanco 80%
- Nombre de tienda: "Imaquinaria" Archivo semi-expanded, #5A5258, pie
```

### Post de nivel / felicitación de cliente
```
Fondo: #211A23 (negro)
- Dragón grande como marca de agua, opacidad 10%, rojo
- Badge de nivel: rectángulo redondeado #4D2559 (premium) o neutro
- Nombre del nivel: Archivo semi-expanded, blanco, grande (32pt+)
- "El Sendero del Bushidō": Noto Serif JP, #9E9399, pequeño
- Logo: blanco, pie centrado
```

### Story de producto / novedad
```
Fondo: #211A23 o imagen de producto
- Barra superior: 6px, #E81036
- Barra inferior: 6px, #E81036
- Texto en zona segura (140px de margen en top y bottom)
- CTA sticker: fondo #E81036, texto blanco, border-radius 99px
```

## Avatar y foto de perfil

- **Usar siempre:** solo el isotipo del dragón (`assets/dragon-icon.png`)
- **Nunca:** el logo completo (wordmark + dragón) como avatar — el texto queda ilegible
- Fondo del avatar: blanco `#FFFFFF` o transparente
- No añadir marco ni filtros al isotipo

## GIFs y animaciones de marca

Principios:
- Duración máxima: 3-6 segundos para loops
- Sin texto animado complejo — legibilidad en móvil primero
- El dragón puede rotar o pulsar suavemente — sin distorsión
- Paleta: exclusivamente los colores de marca definidos arriba
- Framerate: 24fps para suavidad

## Tono visual en redes

- **Dinámico pero limpio.** Mucho espacio en blanco. Evitar saturar el frame.
- **Producto con contexto.** Las fotos de productos se muestran en ambiente (manos,
  escritorio, estantería) — no sobre fondo blanco plano a menos que sea intencional.
- **El dragón tiene presencia.** No esconderlo — es el símbolo central de la marca.
- **Consistencia de fondo.** Alternar entre fondo blanco `#FFFFFF`/`#F5F4F2` y
  fondo negro `#211A23` para variedad, sin mezclarlos en el mismo post.
