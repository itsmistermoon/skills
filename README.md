# skills

Claude skills for the captain, versioned in this repo and organized into groups. Each group is a folder under [`skills/`](skills/) with its own `README.md` that lists its skills.

## Groups

- **[branding](skills/branding/README.md)**: brand identity and logo construction.
- **[misc](skills/misc/README.md)**: general-purpose skills without a dedicated theme.
- **[mission-control-center](skills/mission-control-center/README.md)**: `mcc`, session memory, task tracker, away mode, fleet coordination, and situation reports for agent work in a repo.
- **[wiki-radiant](skills/wiki-radiant/README.md)**: personal knowledge base (ingest, query, lint).
